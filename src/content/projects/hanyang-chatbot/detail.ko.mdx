## 프로젝트 소개

**"스크립트 한 줄로 임베드되는 AI 챗봇 위젯"**

Orca AI의 SaaS형 AI 챗봇 플랫폼에서 한양대학교 창업지원단을 비롯한 여러 고객사 웹사이트에 임베드되는 챗봇 위젯의 프론트엔드를 전담 개발했습니다. 고객사는 `<script>` 태그 한 줄과 `orca.setup(websiteId)` 호출만으로 위젯을 설치할 수 있고, 서버 설정만으로 브랜딩·레이아웃·언어가 자동 적용되는 멀티테넌트 구조입니다.

임베드 위젯의 최대 난제인 "호스트 사이트에 영향을 주지 않는 UI"를 Shadow DOM 기반 스타일 격리로 해결했고, LLM 답변의 토큰 단위 스트리밍 렌더링과 한글 IME 안전 입력까지 구현했습니다.

> 이 서비스는 현재 운영이 종료된 상태입니다.

## 회고

**"임베드 위젯을 처음부터 끝까지 설계한 경험"**

### 1. 처음으로 만든 임베드 위젯 — Shadow DOM과 단일 스크립트 배포

Shadow DOM도, 스크립트 한 줄로 동작하는 위젯도 이 프로젝트에서 처음 만들어봤습니다. 호스트 사이트의 CSS는 통제할 수 없다는 전제에서 출발해, 호스트에 영향받지 않는 구조를 보장하는 것은 코드 수정이 아니라 구조(Shadow DOM 격리, 스타일 주입 위치 제어, 단일 번들 산출)에서 나온다는 것을 배웠습니다. 번들 크기, 스타일 격리, 설치 간결성 같은 임베드형 제품의 핵심 제약을 제품 관점에서 이해하게 된 프로젝트였습니다.

### 2. 웹사이트 ID 하나로 자가 구성되는 구조를 택한 이유

고객사마다 문구·색상 같은 커스터마이징 요청이 생겨도 제품 코드를 수정하지 않고 흡수하기 위해, 서버에서 내려받는 사이트 설정으로 위젯이 스스로 구성되는 멀티테넌트 구조를 택했습니다. 고객사가 늘어나도 배포 없이 사이트 설정만으로 대응하는 것을 목표로 했습니다.

### 3. 임베드 환경의 제약 속 디버깅·QA

호스트 사이트를 통제할 수 없는 환경이라, 개발용 테스트 페이지에 위젯을 심어 단독 동작을 먼저 검증하고, 고객사 페이지에서는 브라우저 콘솔 로그를 활용해 문제를 좁히는 방식으로 디버깅과 QA를 진행했습니다.
