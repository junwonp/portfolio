## Project Overview

**"A white-label AI chatbot widget embedded with a single script tag"**

As the dedicated frontend engineer at Orca AI's SaaS chatbot platform, I built the embeddable chatbot widget for client websites, including the Hanyang University Startup Support Foundation. Clients install the widget with one `<script>` tag and a single `orca.setup(websiteId)` call, and branding, layout, and language apply automatically from server settings — a fully multi-tenant architecture.

The hardest problem in third-party widgets — "never break, no matter which site it's embedded in" — was solved structurally with Shadow DOM style isolation, along with token-level LLM streaming and Korean IME-safe input.

> This service has since been discontinued.

## Retrospective

**"Designing an embed widget end to end for the first time"**

### 1. My first embed widget — first time with Shadow DOM and single-script delivery

Both Shadow DOM and a widget that runs from a single script tag were firsts in this project. Starting from the premise that host page CSS is uncontrollable, I learned that the "never breaks, wherever it's embedded" guarantee comes from structure — Shadow DOM isolation, style-injection placement, a single-bundle artifact — not from patches. This project shaped how I now think about the core constraints of embedded products: bundle size, style isolation, and installation simplicity.

### 2. Flaws confirmed in the code, and how I would fix them

- **Duplicate `key` in carousel/chip lists**: The `message.children.map` keys were fixed strings — incorrect from React's reconciliation standpoint. I would now use `child.id ?? index` based keys.
- **`<link>` appended inside `<style>`**: Placing font `<link>` tags as children of a `<style>` element is unstable per the HTML spec. Appending directly to the Shadow Root or using Constructable Stylesheets was the right approach.
- **Dark-mode initial value always `light`**: OS dark-mode users saw a light flash on first entry. The initial value should have come from `matchMedia('(prefers-color-scheme: dark)')`.
- **`useMediaQuery` dependency array**: Listeners were re-attached whenever `matches` changed. Depending on `[query]` alone, with a functional state update, is sufficient and safer.

### 3. Contract-driven collaboration and frontend ownership

As the consumer of the platform SDK (`@orca.ai/pulse`), I co-maintained API contract documents in the repository with the backend team and developed in parallel. All 270 commits followed issue-based branches, PR reviews, and conventional commits, and the frontend area was fully owned (zero backend commits). Consuming the SDK on top of an understanding of the RAG backend laid the foundation for growing into a full-stack-context frontend engineer.
